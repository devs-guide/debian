Setup runners

These entrypoints establish the baseline host or provide shared support to opt-in features. Published executable URLs always end in .sh.

Start with the baseline

wget -qO- https://devs-guide.github.io/debian/setup/bootstrap.sh | bash

Choose an opt-in runner below only after reviewing its full policy example; the baseline does not implicitly install every feature.

  • Bootstrap — baseline Ansible bootstrap.
  • Debian compatibility entrypoint — compatibility alias for the baseline bootstrap flow.
  • Metal compatibility entrypoint — compatibility alias for the baseline bootstrap flow.
  • Hardware — opt-in source-neutral host baseline.
  • Autologin — console autologin only.
  • Release helper — shared runner support.
  • Shared setup runner — delegated-root and dependency-manifest scaffolding, including the legacy migration inventory.
  • Essential packages — manual baseline reference, not an automation entrypoint.
  • Prerequisites — manual first-host reference.
