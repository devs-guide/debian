Metal compatibility entrypoint

setup/metal.sh remains a published compatibility entrypoint for the baseline bootstrap flow.

wget -qO- https://devs-guide.github.io/debian/setup/metal.sh | bash

It is a compatibility entrypoint for the baseline bootstrap behavior, not a hardware/GPU installer. Use the Hardware or NVIDIA documentation for those separate policies.

For current instructions, use the bootstrap runner documentation.
