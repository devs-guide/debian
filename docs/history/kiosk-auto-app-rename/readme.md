# Kiosk auto-app rename history

`auto.app` was renamed to `kiosk.app`.

The active documentation is the [kiosk app runner](/debian/cli/kiosk.app/),
and the executable source URL is:

```bash
wget -qO- https://devs-guide.github.io/debian/setup/cli/kiosk.app.sh | bash
```

The old `docs/auto.app.md` note remains in the repository as retained source
material; its local absolute link is not used in public documentation.
